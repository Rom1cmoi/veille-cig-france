Comportement du Soleil

Ce qu’on surveille
  • Régions actives : zones de champ magnétique intense (taches) d’où partent les éruptions.
  • Éruptions : classées A, B, C, M, X selon le flux de rayons X ; chaque lettre vaut dix fois la précédente.
  • CME : nuages de plasma qui mettent 1 à 3 jours pour atteindre la Terre.
  • Vent solaire : flux continu, lent (~400 km/s) ou rapide (~700 km/s) lorsqu’il sort d’un trou coronal.
